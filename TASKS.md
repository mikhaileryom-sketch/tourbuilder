ЗАДАЧИ
Задача 1. Загрузка фото напрямую из галереи
Проблема: сейчас фото добавляется только через ссылку на внешний сайт. Нужна загрузка с устройства.

Что сделать:

Заменить <input type="url"> на <input type="file" accept="image/*"> в:

форме создания профиля артиста (openCreateForm)

форме редактирования основного (editMain)

вкладке «Медиа» личного кабинета

форме создания площадки (если будет реализована)

При выборе файла — сжимать изображение на клиенте до 800×800 px через <canvas> (чтобы не грузить тяжёлые файлы в Google Drive).

Загружать файл в Google Drive через Apps Script:

В Code.gs добавить функцию uploadPhoto(base64, filename):

javascript
function uploadPhoto(base64, filename) {
  const folder = DriveApp.getFolderById('FOLDER_ID'); // папка в Google Drive
  const blob = Utilities.newBlob(Utilities.base64Decode(base64), 'image/jpeg', filename);
  const file = folder.createFile(blob);
  file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
  return 'https://drive.google.com/uc?id=' + file.getId();
}
В doPost добавить обработчик action: 'uploadPhoto'.

В форме показать превью выбранного фото до сохранения.

После загрузки — сохранять полученный URL в Artists.img.

Критерии:

Пользователь тапает на поле фото → открывается выбор файла из галереи телефона.

После выбора — превью показывается сразу.

При сохранении фото уходит в Google Drive и привязывается к профилю.

Старый способ через URL оставить как альтернативу (кнопка «или вставить ссылку»).

Задача 2. Календарь не сохраняется
Проблема: при сохранении расписания появляется надпись «сохранено», но по факту данных нет. В отладке: «пусто (всего: 0 артист айди 11)».

Что сделать:

Проверить, что в Code.gs обработчик setPrice / setPriceBatch корректно пишет в лист ArtistPricing:

artistId — должен быть числом или строкой, но консистентно с Artists.id

date — в формате YYYY-MM-DD

priceModifier — число

note — строка

Проверить, что чтение action: 'pricing' возвращает все записи для конкретного artistId:

В getSheetData для типа pricing добавить фильтр по artistId, если он передан в параметре.

Endpoint: ?action=pricing&artistId=11 → массив записей.

В index.html — при открытии экрана «Управление ценой»:

Загружать данные из API для текущего artistId.

Если API вернул пустой массив — показывать «Нет сохранённых цен» (а не «пусто»).

После сохранения — перезагружать данные из API, а не полагаться на локальный кэш.

В renderWheel / renderCalendar — при подсчёте «лучей» (модификаторов) использовать реальные данные из ArtistPricing, а не заглушки.

Добавить console.log для отладки:

javascript
console.log('artistId:', currentArtist.id);

console.log('saving:', { artistId, date, priceModifier });
Критерии:

При сохранении цены — запись реально появляется в Google Sheets.

После перезагрузки страницы сохранённые цены отображаются.

Число «лучей солнышка» соответствует количеству сохранённых модификаторов.
